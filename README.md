**Guest Experience Analytics & Topic Modelling System**  
*Comprehensive Natural Language Processing & BERTopic Pipeline*

---

## Project Overview

This project implements the guest sentiment analytics and topic modelling workflow for Montra Hospitality Intel.

The pipeline extracts operational hotel records and guest feedback from a PostgreSQL database hosted on NeonDB, conducts exploratory data analysis, cleans and normalizes review text, and configures topic modelling using BERTopic to surface operational hospitality themes without geographic bias.

## Core Guidelines & Workflow
 
### 1. Database Security & Credential Hygiene
- **Zero Hardcoded Secrets**: Raw database connection strings containing plaintext passwords must never be committed to GitHub.
- **Environment Management**: Database credentials are stored in `.env` and loaded securely with `python-dotenv`:
  ```python
  from dotenv import load_dotenv, find_dotenv
  load_dotenv(find_dotenv() or "../.env")
  Database_url = os.getenv("DATABASE_URL")
  ```
- **Git Protection**: `.env` is ignored in `.gitignore`, while `.env.example` provides the connection template.

---

### 2. Notebook 1: Data Extraction & EDA (`notebook/01_data_extraction and eda.ipynb`)
- **Connection**: Connects to the NeonDB PostgreSQL database via SQLAlchemy engine with `sslmode=require`.
- **Inspection**: Discovers public schema tables (`bookings`, `guests`, `hotels`, `reviews`).
- **Exploratory Data Analysis**:
  - Room type counts and revenue generated by room type.
  - Booking channel distribution and revenue by channel.
  - Stay duration distribution.
  - Visualized via a 3x2 Plotly subplots grid (`fig = make_subplots(rows=3, cols=2)`).
- **Data Consolidation**: Performs relational inner joins across `reviews`, `bookings`, `guests`, and `hotels`.
- **Output**: Exports 35,000 merged records to `data/processed/merged_raw.csv`.

---

### 3. Notebook 2: Text Preprocessing (`notebook/02_text_preprocessing.ipynb`)
- **Corpus Audit**: Inspects missing values in `review_text` and checks for duplicate reviews.
- **Deduplication**: Drops duplicate reviews using `merged.drop_duplicates(subset=['review_text'])`.
- **Whitespace Cleaning**: Filters out records that contain only whitespace.
- **Review Length Profiling**: Calculates character lengths (`review_corpus['review_text'].str.len()`).
- **Standard Cleaning Pipeline (`clean_review`)**:
  - Converts text to string.
  - Strips HTML tags (`<.*?>`).
  - Removes URLs (`https?://\S+|www\.\S+`).
  - Removes emojis by encoding/decoding to ASCII.
  - Converts to lowercase.
  - Retains alphanumeric characters and spaces (`[^a-z0-9\s]`).
  - Trims and normalizes whitespace (`re.sub(r'\s+', ' ', text).strip()`).
- **Output**: Exports cleaned dataset to `data/processed/montra_cleaned_data.csv`.

---

### 4. Notebook 3: Topic Modelling (`notebook/03_topic_modelling.ipynb`)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/earlchirchir/Guest-Experience-Analytics/blob/main/notebook/03_topic_modelling.ipynb)

*Execute this notebook using Google Colab with GPU hardware acceleration (T4 GPU) for fast transformer embedding generation and BERTopic clustering.*

- **Corpus Ingestion**: Loads `data/processed/montra_cleaned_data.csv` and converts `cleaned_review_text` into document lists.
- **Geographic Entity Stripping**: Removes UK city names (`London`, `Manchester`, `Edinburgh`, `Birmingham`, `Leeds`, `Bristol`, `Liverpool`, `Glasgow`, etc.) using regex so that discovered topic clusters focus on hotel service quality and operational touchpoints rather than geographic location.
- **Duplicate & Vocabulary Audit**: Standardizes review cases, calculates duplicate rates with `Counter`, and measures total vocabulary size.
- **Sentence Embeddings**: Converts reviews into 384-dimensional dense semantic vectors using `SentenceTransformer('all-MiniLM-L6-v2')`.
- **Modular BERTopic Pipeline**:
  - **UMAP**: Non-linear dimensionality reduction (`n_neighbors=15`, `n_components=5`, `metric='cosine'`).
  - **HDBSCAN**: Density-based clustering (`min_cluster_size=15`, `metric='euclidean'`).
  - **CountVectorizer**: Stopword filtering and n-gram extraction.
  - **c-TF-IDF**: Extracts class-based term representations for each topic cluster.

## Instructions to Run

### 1. Environment Setup
```bash
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your NeonDB PostgreSQL credentials:
```bash
cp .env.example .env
```
Ensure your `.env` contains:
```env
DATABASE_URL=postgresql+psycopg2://<username>:<password>@<host>/<database>?sslmode=require
```

### 3. Run the Notebooks
Launch Jupyter Lab or Jupyter Notebook:
```bash
jupyter notebook
```
Execute the notebooks in sequence:
1. `notebook/01_data_extraction and eda.ipynb`
2. `notebook/02_text_preprocessing.ipynb`
3. `notebook/03_topic_modelling.ipynb`
